Capacidades principales

Cada bloque conecta a una página dedicada o a una sección verificable.

Detección multicapa de agentes

Cocxy detecta agentes locales mediante hooks, señales OSC, semántica de terminal, patrones y heurísticas de tiempo.

  • 11 perfiles integrados
  • agents.toml propio
  • Estado por superficie

Bóveda cifrada

Busca, reanuda, fija, previsualiza y exporta sesiones locales sin enviar historial de terminal a un servicio remoto.

  • Cifrado local
  • Búsqueda de texto
  • Reanudación inteligente

Revisión de código en línea

Revisa cambios del agente junto a la terminal, comenta líneas, acepta o rechaza bloques y devuelve observaciones estructuradas.

  • Árbol de archivos y diff
  • Comentarios por línea
  • Flujo por teclado

Espacio Markdown

Un espacio nativo con vista previa, índice, bloques de código, diagramas, matemáticas, exportación y archivos locales.

  • Vista en vivo
  • Mermaid y KaTeX
  • Rutas de exportación

Panel de GitHub

Mantén pull requests, issues, checks, releases y contexto del repositorio junto a la terminal sin crear una cuenta de Cocxy.

  • Usa gh auth
  • Checks y releases
  • Contexto local

Navegador incorporado

Previsualiza localhost, inspecciona páginas, mantiene perfiles aislados y coloca el navegador junto a la terminal.

  • Perfiles
  • Herramientas de inspección
  • Flujo dividido

Espacios remotos

SSH, proxy, relay, daemon y transferencia de archivos se tratan como acciones explícitas bajo control local.

  • Multiplexing SSH
  • SOCKS y CONNECT
  • Entrega SFTP

Motor de terminal con GPU

CocxyCore combina núcleo Zig, ABI C, atlas de glifos, manejo PTY y renderizado Metal para rendimiento nativo en macOS.

  • Núcleo Zig
  • Renderizador Metal
  • Semántica PTY

CLI complementaria

Automatiza ventanas, pestañas, agentes, hooks, Bóveda, navegador, Markdown, remotos, configuración, temas y diagnósticos.

  • Salida JSON
  • Socket local
  • Scripts de shell

Integración de shell

Wrappers para zsh, bash y fish preservan dotfiles y añaden cwd, límites de comandos y apertura de navegador.

  • zsh, bash, fish
  • cwd con OSC 7
  • bloques OSC 133

Sistema de plugins

Hooks locales extienden Cocxy de forma transparente, con permisos explícitos y pocas dependencias.

  • Eventos
  • Manifest TOML
  • Ejecución local

Cero telemetría

Cocxy se distribuye sin SDK de analíticas, subida automática de fallos, cuentas obligatorias, rastreo o telemetría de sesiones.

  • Sin SDK de analíticas
  • Sin cuenta
  • Sin subida de sesiones
