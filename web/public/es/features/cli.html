CLI complementaria

Automatiza ventanas, pestañas, agentes, hooks, Bóveda, navegador, Markdown, remotos, configuración, temas y diagnósticos.

Capacidades

  • Salida JSON
  • Socket local
  • Scripts de shell

Control automatizable

Ventanas, pestañas, divisiones, Bóveda, Markdown, navegador, remoto y diagnósticos se pueden manejar desde shell.

Salida JSON

La salida legible por máquinas mantiene pipelines con jq y checks locales.

Socket local

El socket de la app opera en la máquina del usuario.

Local primero

La función opera desde tu Mac o desde conexiones que inicias explícitamente.

Sigue explorando

Integración de shell

Wrappers para zsh, bash y fish preservan dotfiles y añaden cwd, límites de comandos y apertura de navegador.

Sistema de plugins

Hooks locales extienden Cocxy de forma transparente, con permisos explícitos y pocas dependencias.

Cero telemetría

Cocxy se distribuye sin SDK de analíticas, subida automática de fallos, cuentas obligatorias, rastreo o telemetría de sesiones.
