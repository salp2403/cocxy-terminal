Espacio Markdown

Un espacio nativo con vista previa, índice, bloques de código, diagramas, matemáticas, exportación y archivos locales.

Capacidades

  • Vista en vivo
  • Mermaid y KaTeX
  • Rutas de exportación

Escritura junto a la terminal

Los archivos Markdown pueden vivir junto a terminal, navegador y revisión.

Documentos completos

Índice, código, diagramas, matemáticas, notas, tareas, imágenes y exportación forman parte del espacio.

Archivos locales

Los documentos permanecen en el sistema de archivos del proyecto para Git y copias locales.

Local primero

La función opera desde tu Mac o desde conexiones que inicias explícitamente.

Sigue explorando

Panel de GitHub

Mantén pull requests, issues, checks, releases y contexto del repositorio junto a la terminal sin crear una cuenta de Cocxy.

Navegador incorporado

Previsualiza localhost, inspecciona páginas, mantiene perfiles aislados y coloca el navegador junto a la terminal.

Espacios remotos

SSH, proxy, relay, daemon y transferencia de archivos se tratan como acciones explícitas bajo control local.
