Sin tubería de telemetría

No hay SDK de analíticas, subida automática de fallos ni recolector oculto de eventos.

Red explícita

Updates, SSH, GitHub, navegador y plugins usan red solo cuando el usuario lo inicia o configura.

Verificable

El código público, monitores locales y la página de privacidad explican qué revisar.
