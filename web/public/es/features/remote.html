Capacidades

  • Multiplexing SSH
  • SOCKS y CONNECT
  • Entrega SFTP

Flujo con SSH

ControlMaster, sesiones persistentes, transferencia de archivos y terminal operan sobre acciones SSH explícitas.

Proxy y relay

SOCKS5, HTTP CONNECT, autenticación de relay y registros locales marcan límites claros.

Sesiones recuperables

Reconectar y adjuntar preserva contexto sin ocultar operaciones de red.

Captura del flujo

Local primero

La función opera desde tu Mac o desde conexiones que inicias explícitamente.
