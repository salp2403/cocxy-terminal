Privacidad

Cero telemetría es un detalle verificable de implementación, no una promesa de marketing.

PrivacidadQué no haceRed explícitaCómo verificarPrivacidad web

Qué no hace Cocxy

  • Sin SDK de analíticas
  • Sin subida automática de fallos
  • Sin cuenta obligatoria
  • Sin rastreo de visitantes
  • Sin telemetría de sesiones

Acceso de red explícito

Las únicas rutas de red son updates firmados, navegador que tú abres, SSH que tú inicias, operaciones GitHub con tu autenticación y plugins que aceptas.

Cómo verificar

Revisa el código público, ejecuta monitores locales como LuLu o Little Snitch, inspecciona la configuración de Sparkle y valida que no haya cookies ni scripts externos.

Privacidad web de este sitio

Este sitio no escribe cookies. JavaScript usa localStorage solo para cocxy-theme y no carga rastreadores.
