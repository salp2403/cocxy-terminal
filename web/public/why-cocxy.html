Cocxy Terminal

Why Cocxy

A terminal designed around local-first agent workflows on macOS.

Native macOS

Swift, AppKit, and Metal on top of the CocxyCore engine, with no web layer for the terminal.

Local-first

Sessions, Vault, projects, and reviews live on your Mac; the network is used only when you ask.

Open source, MIT

The app is public on GitHub under the MIT license, so you can read, build, and audit it.

Agents are first-class

Detection, the agent panel, review, and the Vault are designed around how coding agents work.

21 languages

The app interface is localized into 21 languages.

Zero telemetry

No analytics, no automatic crash upload, and no account, so there is nothing to opt out of.

Focused stewardship

A native terminal for agent work, not a platform that grows in every direction.
