Why Cocxy

Built around agents, not bolted on.

Cocxy treats every agent session as something to understand, not just text scrolling by.

Agent-aware

Four detection layers (hooks, terminal signals, process patterns, and timing) tell you when an agent is thinking, working, waiting for you, or done.

Local-first

Sessions, the encrypted Vault, projects, and reviews stay on your Mac. Cocxy has no analytics, no automatic crash upload, and no account.

Native to the core

Swift and AppKit on top of CocxyCore, a terminal engine written in Zig and rendered with Metal on the GPU.

Code review

Read the diff before it lands.

Open the review panel beside the terminal, comment on any line, accept or reject each change, and send structured notes straight back to the agent’s session.

Projects

Projects, not just folders.

Each repository gets its own home for sessions, notes, and tasks. Clone it once, and every agent you start there stays with the project.

Phone mirror

Your agents, in your pocket.

Pair your phone with a QR code and follow sessions from its browser: read the output, answer an agent that is waiting, or approve its next step. Everything travels end-to-end encrypted, with no account and no Cocxy cloud in between.

Features

Everything around the agent, built in.

Terminal, review, Vault, browser, Markdown, and remotes share one native window.

Multi-Layer Agent Detection

Cocxy detects local coding agents through hooks, OSC signals, terminal semantics, pattern matching, and timing heuristics.

Encrypted Vault

Search, resume, pin, preview, and export local agent sessions without sending terminal history to a remote service.

Inline Code Review

Review agent changes beside the terminal, comment on lines, accept or reject hunks, and return structured feedback to the session.

Markdown Workspace

A native writing surface with preview, outline, code blocks, diagrams, math, exports, and local file workflows.

GitHub Pane

Keep pull requests, issues, checks, release pages, and repository context next to the terminal without adding a Cocxy account.

Built-in Browser

Preview localhost, inspect pages, keep profiles isolated, and place the browser beside terminal panes.

Remote Workspaces

SSH, proxy, relay, daemon, and file-transfer paths are designed as explicit user actions with local control.

GPU Terminal Engine

CocxyCore combines a Zig terminal core, C ABI, glyph atlas hardening, PTY handling, and Metal rendering for native macOS performance.

CLI Companion

Script windows, tabs, agents, hooks, Vault, browser, markdown, remotes, configuration, themes, and diagnostics.

Shell Integration

zsh, bash, and fish wrappers preserve user dotfiles while adding cwd, command-boundary, and browser-open signals.

Plugin System

Local plugin hooks extend Cocxy while staying transparent, permissioned, and dependency-light.

Zero Telemetry

Cocxy ships without analytics SDKs, automatic crash upload, required accounts, visitor tracking, or session telemetry.

How it works

From prompt to review, in three steps.

  1. Start an agent

    Run it in any tab or pane. Cocxy picks it up with no setup.

  2. Follow it without watching

    Its state shows in the sidebar, the agent panel, and your phone, and Cocxy tells you when it needs you.

  3. Review and decide

    Read the diff beside the terminal, comment, and send your notes back to the same session.

FAQ

Before you install.

All questions

Does Cocxy require an account?

No. Cocxy installs and runs locally without signing in.

Do my sessions leave my Mac?

Not through telemetry. Cocxy uses the network only when you open the browser, connect over SSH, use GitHub, check for updates, run plugins, or pair a phone.

Which agents does it work with?

Eleven built-in profiles cover the most popular coding CLIs, and you can add any other command-line agent in agents.toml.

Is it open source?

Yes. Cocxy is MIT licensed and its source is public on GitHub.

How do updates work?

Releases are signed and notarized, and the built-in updater installs new versions. You can also upgrade through Homebrew.
